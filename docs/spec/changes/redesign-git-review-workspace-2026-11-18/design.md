# 桌面 Git 评审设计

## 工作区布局

```text
现有工作区导航与项目入口
┌───────────────────┬────────────────────┬────────────────────────────────┐
│ Git               │ 变动文件            │ 差异                           │
│ 分支与同步          │ 路径筛选 · 状态      │ 比较范围 · 文件路径 · 变更导航   │
│ 更改 / 历史         │ 文件名 · 目录 · 状态 │ 可切换并排与统一视图             │
└───────────────────┴────────────────────┴────────────────────────────────┘
```

项目导航和工作区标签仍承担切换职责。进入评审时，装载同一个 Git 侧栏视图，并从布局中移除工作树与常用命令所在列及其分隔线。两个列表列的宽度可调，差异区承接剩余宽度。窄窗口优先切换为统一 diff，可临时收起 Git 侧栏腾出空间。文件名和状态列保留足够对比度，使用 Codux 现有主题。

### 侧栏可见性

Git 侧栏在非评审工作区使用独立的打开或关闭偏好。它可以跨终端和文件视图常驻，与评审和通用助手面板的状态分别管理。进入评审时临时展开，评审内的独立开关允许收起和重开，受影响的宽度随之回收。退出评审时使用用户设置的非评审偏好，恢复工作树与常用命令所在列原有的展开状态。再次进入评审时默认展开 Git。

只挂载一个 Git 侧栏实例。切换视图时延续当前仓库对应的草稿、侧栏标签和滚动状态。当前项目与工作树通过评审范围标识和现有项目入口识别。

| 当前动作 | Git 侧栏 | 工作树与常用命令列 |
| --- | --- | --- |
| 在终端或文件里打开 Git | 立即打开，并在这些工作区间保持 | 跟随现有布局偏好 |
| 从其他工作区进入评审 | 自动打开 | 隐藏并回收宽度 |
| 在评审里收起或重开 Git | 仅影响本次评审 | 隐藏 |
| 从评审返回终端或文件 | 恢复非评审可见性偏好 | 恢复原布局设置 |

## 文件行宽度与悬停

文件名、目录和状态在同一行布局。先预留图标、间距和末尾状态的实际渲染宽度，再分配剩余空间。文件名的自然宽度优先，目录承接剩余空间并先截断。根目录文件省去目录节点及其间距。只有去掉目录后文件名仍装不下时，文件名才截断，尽可能保留可用于识别的后缀。

鼠标在文件行内停留时显示多行提示，包含完整文件名、仓库相对路径、变更状态和已有的增删行数。长路径在窗口内可读，重命名显示旧路径与新路径。移开鼠标、滚动或切换视图后关闭提示。整行单击仍进入差异。提示复用现有数据和悬停层，无需新 Git 请求；旧路径可随重命名的比较结果提供。

当前 `git_review_file_row` 在文件名节点使用 `max_w(relative(0.6))`，目录节点即使没有文本也创建。实施时检查父容器参与布局的真实宽度，使用中英文长名、共享前缀、根目录和深目录分别验证。

## Git 操作与评审范围

侧栏顶部保留分支、同步与刷新。「更改」聚合提交草稿和暂存操作，工作区干净时折叠空分组并提供历史入口。「历史」可搜索和分页，选择提交或按 Enter 在评审区显示提交详情及其变更文件。侧栏和评审文件列表共享当前仓库范围，各自保留角色和选择状态。

评审显示比较的起点和终点。未提交可查看 `HEAD → 暂存区` 或 `暂存区 → 工作区`。分支比较默认显示共同祖先到目标分支，可显式切换为端点直接比较。提交详情以父提交到选中提交为范围，合并提交可切父，根提交使用空树。文件列表按路径筛选，并支持文件和变更块导航。

刷新期间保留上一次有效快照，并显示刷新反馈。将工作区干净、无匹配、加载失败和不可预览区分为可辨认的状态。按评审范围与选择版本应用异步结果，快速换文件或切工作树时显示最新选择对应的差异。文件列表和差异内容按可见区域渲染。
